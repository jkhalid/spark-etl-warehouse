# Spark ETL Warehouse Project

## Overview
High-performance ETL pipeline with complex joins and optimization for data warehouse.

## Week 1: Local Development
- Dataset: Brazilian E-Commerce (Kaggle)
- Focus: Join optimization, partitioning, baseline metrics

## Week 2: Cloud Testing
- Docker + Kubernetes deployment
- AWS EMR + Databricks benchmarking
- Platform comparison

## Structure
- `src/`: PySpark code
- `data/`: Datasets (gitignored)
- `k8s/`: Kubernetes manifests
- `docs/`: Architecture docs
- `notebooks/`: Jupyter exploration
